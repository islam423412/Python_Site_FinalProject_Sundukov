📦 Аренда одежды — Web-проект по Django

Проект реализует сервис аренды вечерних платьев и костюмов. Пользователи могут создавать объявления о сдаче вещей в аренду, искать наряды по названию или локации, оставлять отзывы с рейтингом от 1 до 5 звёзд.
Администраторы сайта имеют доступ к модерации объявлений через специальный интерфейс.

🛠️ Стек технологий
Python/Django 5.x
PostgreSQL (в контейнере)
Bootstrap 5 (для фронтенда)
Gunicorn + Nginx (через Docker Compose)
⚡ Запуск проекта (Docker)

Для запуска используется инфраструктура Docker. Все зависимости устанавливаются автоматически при сборке образа.
Шаг 1. Клонирование репозитория
bash
Копировать
git clone https://github.com/islam423412/Python_Site_FinalProject_Sundukov.git
cd Python_Site_FinalProject_Sundukov

(Если у вас уже скачана эта папка, шаг можно пропустить).

Шаг 2. Сборка и запуск контейнера

Запустите проект одной командой. Это создаст базу данных, применит миграции и соберёт статику.

bash
Копировать
docker-compose up --build -d # Флаг "-d" запускает контейнеры в фоне

(Ваши действия видны в логах терминала, но сайт работает без них).

Шаг 3. Создание администратора

Откройте второй терминал (Ctrl+Shift+T) внутри той же папки и выполните:

bash
Копировать
docker-compose exec web python manage.py createsuperuser

Создайте пользователя с правами админа (логин/пароль). Он будет нужен для доступа к модерации и панели /admin.


🔑 Требования к окружению

Для локального запуска вне Docker требуется:

Python >= 3.9
Пакеты из файла requirements.txt
База данных PostgreSQL (рекомендуется), либо SQLite для тестов.

Переменные окружения берутся из файла .env, пример которого лежит в корне как .env.example.
